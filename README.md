# ✨ Features

## 🎯 Quiz Categories

QuizMaster provides multiple categories for different learning areas:

- 🧮 Aptitude
- 💻 Programming
- 🤖 AI & Machine Learning
- 🌐 Web Development
- 🗄️ Database
- 🔐 Cyber Security
- 🌍 General Knowledge

Each category contains its own set of questions.

---

## ⚡ Difficulty Levels

Players can select their preferred difficulty:

- 🟢 Easy
- 🟠 Medium
- 🔴 Hard

---

## ⏱️ Timed Quizzes

Every question has a countdown timer.

Players need to answer before the timer reaches zero.

This makes the quiz more challenging and interactive.

---

## 🪙 Coin & Reward System

Players earn coins by completing quizzes.

Coins can be used to unlock rewards such as:

| Reward | Cost |
|---|---:|
| 🥉 Bronze Badge | 100 Coins |
| 🥈 Silver Badge | 250 Coins |
| 🥇 Gold Badge | 500 Coins |
| 🏆 Quiz Champion | 1000 Coins |

---

## 🏆 Leaderboard

QuizMaster includes a leaderboard where players can compare their performance.

The leaderboard displays:

- Player rank
- Player name
- Quiz score
- Number of quizzes completed
- Top 3 players

---

## 📊 Progress Tracking

The application tracks important player statistics:

- Completed quizzes
- Total coins
- Best score
- Player level
- Rewards unlocked

---

QuizMaster uses a modern UI design with:
